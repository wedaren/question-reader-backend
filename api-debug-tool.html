🔧 问题阅读器 API 调试工具

微信小程序后台接口测试与文档

GET健康检查 ▼
/health

描述: 检查服务是否正常运行

GET获取知识库结构 ▼
/v1/kb/structure

描述: 获取完整的问题树结构和关注列表

缓存: 支持 ETag 缓存，5分钟有效期

GET获取问题内容 ▼
/v1/kb/issue?path={filePath}

描述: 根据文件路径获取具体问题的详细内容

GET获取同步状态 ▼
/v1/kb/sync-status

描述: 查看 Git 仓库的同步状态

POST手动触发同步 ▼
/v1/kb/force-sync

描述: 手动触发 Git 仓库同步

注意: 此操作可能需要较长时间完成
